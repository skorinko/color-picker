Support

Turning it on, using it, and what to do when something doesn’t work.

Turn it on: Mac

  1. Open the Color Picker for Safari app once. Its window shows whether the extension is on.
  2. Click Quit and Open Safari Settings…, or in Safari choose Safari › Settings › Extensions.
  3. Tick Color Picker. It needs no access to your websites, so there’s nothing else to allow.

Turn it on: iPhone and iPad

  1. Open Settings, then Apps, then Safari, then Extensions.
  2. Tap Color Picker and turn on Allow Extension.

Then open any web page, such as the demo page, and try it.

Use it

  • Pick a color: click the Color Picker button in the Safari toolbar, then Pick a Color, or press ⌃⇧C. Move over the page and click. On iPhone and iPad, tap the page menu button beside the address, then Color Picker, then Pick a Color; drag your finger and lift it.
  • Pixel or element: the bar at the top of the page switches between Pixel (the color on the screen) and Element (the CSS colors of the element under the pointer). 1×1, 3×3 and 5×5 set how many pixels are averaged.
  • Keys: arrow keys move one screen pixel (ten with ⇧), Return picks, Esc stops, P and E switch modes, 1, 3 and 5 set the size, R takes a new picture of the page.
  • Other formats: after a pick, the panel shows the color in every format; click a row to copy it. To change the format every pick is copied in, choose it under Copy as in the toolbar button.
  • A page’s colors: Colors of This Page in the toolbar button, ⌃⇧P, or Palette in the bar while picking.
  • Everything you picked: Open Library in the toolbar button lists your recent picks and your palettes, with export.

Common questions

Nothing happens on a page

Safari doesn’t let extensions into its own pages, such as Settings or the Start Page; the toolbar button says so there. If it happens on a web page, please write to us with the page’s address.

The magnifier says “No screenshot”

Safari didn’t share a picture of the page. On a Mac, Safari shares it only while Safari is the front app: click the page and press R to try again. Element mode works without a picture.

The keyboard shortcut does nothing

A website or another extension may use the same keys. Use the toolbar button instead, or check that the extension is still ticked in Safari’s settings.

The color isn’t the value in the page’s CSS

Pixel mode reads the screen, where edges, text and pictures are blended as they’re drawn. Use element mode for the value the author wrote, including colors wider than sRGB.

How do I move a palette to another device?

In the library, export the palette as plain text, then on the other device paste the list into a palette’s Add colors field.
